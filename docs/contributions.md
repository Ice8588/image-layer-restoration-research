# 個人貢獻與團隊邊界

以下是待本人最終核對的貢獻說明，不以 repository ownership 或 commit author 單獨推定歸屬。

| 維度 | 可支持的工作範圍 | 歸屬狀態 |
|---|---|---|
| Research Design | 特定部件補全問題、baseline、資料與輸入消融、失敗判讀、評估契約 | 研究者主要範圍；個別方法提案者待逐項確認 |
| Implementation | 生成／補全研究功能；本候選的通用 mask／evaluation utilities | 本人已允許公開；完整核心貢獻清單待核對 |
| Experiment Execution | 矩陣、重試、結果與分析整理 | 可見程式與 artifacts；逐輪操作者不由 Git 代推 |
| Evaluation / Annotation | 後續 VLM QA research／implementation、人工結果判讀流程 | 早期分工未包含 QA，後續工作已超出原始分工；具體人工標註者待確認 |
| System Integration | Legacy 功能移植與 standalone workflow | 研究者功能 + 組員自動分層 + 團隊整合；逐模組歸屬待確認 |

早期分工與實際後續貢獻分開：不能把 VLM QA 全部說成他人工作，也不能將 repository 內全部 QA 程式或標註都算成本人獨作。第三方模型、論文方法與原始移植核心不列為個人演算法發明。
