# 研究貢獻

本研究專案由我獨立開發，沒有其他開發者參與。工作範圍包括：

| 範圍 | 內容 |
|---|---|
| 研究設計 | 定義特定部件補全問題，設計 baseline、輸入消融與評估方式 |
| 程式實作 | 生成／補全研究功能、VLM QA、mask 與 evaluation utilities |
| 實驗執行 | 建立實驗矩陣，執行生成、重試與結果整理 |
| 評估分析 | 建立量化與人工判讀流程，分析失敗案例並整理研究結論 |

與其他模組合併的系統成果位於 **Layer Lab** 專案；本 repository 展示此處獨立完成的研究與精選實作。[Layer Lab 操作展示](system_evolution.md)

使用的第三方模型、論文方法與原始美術素材依來源標註，不列為個人原創。來源與使用範圍見 [NOTICE](../NOTICE.md)。
