# 素材來源與授權

本頁記錄公開素材的來源與適用授權。

## Synthetic 素材

Synthetic V1／V2／V3 使用研究者自行生成的素材，經合成建立輸入、部件目標與遮罩，用於控制實驗。Benchmark 的適用範圍見 [評估方法](evaluation.md)。

## Qwen-Image-Layered

來源：[官方 repository](https://github.com/QwenLM/Qwen-Image-Layered)。使用的 input snapshot 為 `54c4fe47e76d745775e03fc66ee38457280ed9ea`，下載入口為 [官方 test_images](https://github.com/QwenLM/Qwen-Image-Layered/tree/54c4fe47e76d745775e03fc66ee38457280ed9ea/assets/test_images)。

該 snapshot 的 [LICENSE](https://github.com/QwenLM/Qwen-Image-Layered/blob/54c4fe47e76d745775e03fc66ee38457280ed9ea/LICENSE) 標示 Apache-2.0；本 repository 附有 [上游授權文字](../assets/prototype/QWEN_SOURCE_LICENSE.txt)。

## Demo Artwork

[Layer Lab Demo](../assets/prototype/Layer_Lab_DEMO.mp4)中的紅色城市、人物、資料夾、相機與白鴿圖像，來源為上述 snapshot 的 [官方 test_images/1.png](https://github.com/QwenLM/Qwen-Image-Layered/blob/54c4fe47e76d745775e03fc66ee38457280ed9ea/assets/test_images/1.png)。原始插圖依上游來源標註。

影片中的遮罩、移除／補全結果與圖層合成為研究衍生內容；影片另經剪輯、加入字幕，並將生成等待段加速。上游素材授權適用於對應來源；本 repository 其他內容的重用條件見 [NOTICE](../NOTICE.md)。
